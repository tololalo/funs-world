Core Features

왜 FUNS Talk인가?

이메일도, 전화번호도 필요 없습니다. 지갑 하나로 시작하는 완전히 새로운 메시징 경험.

🔐

E2E 암호화 메시징

Signal Protocol / NaCl 기반 Double Ratchet 알고리즘으로 Perfect Forward Secrecy를 보장합니다. 서버도 메시지를 읽을 수 없습니다.

👛

지갑 기반 인증

이메일, 전화번호 불필요. 내장 지갑이 자동 생성되고 PIN/생체인증으로 로그인합니다. MetaMask 등 외부 지갑도 연결 가능.

💸

인챗 암호화폐 송금

채팅창에서 바로 BNB, BEP-20 토큰, FunS를 송금합니다. /send @user 100 FunS 한 줄이면 끝.

⛓️

온체인 무결성 검증

메시지 해시를 Merkle Tree로 묶어 opBNB에 기록. 누구나 Merkle Proof로 메시지 존재를 검증할 수 있습니다.

🎫

토큰 게이티드 채널

특정 NFT나 토큰 보유자만 입장 가능한 프리미엄 채널. 커뮤니티의 새로운 가능성을 열어줍니다.

⛽

가스비 제로 경험

ERC-4337 Paymaster로 기본 메시징은 완전 무료. 사용자는 블록체인의 존재조차 느끼지 못합니다.

How It Works

카카오톡처럼, 블록체인으로

복잡한 건 뒤에서. 앞에선 그냥 채팅.

1

앱 설치

설치만 하면 지갑이 자동 생성됩니다. 시드 구문은 암호화 저장.

2

PIN/생체 인증

지문이나 PIN 코드로 간편 로그인. 복잡한 프라이빗키 관리 불필요.

3

채팅 시작

E2E 암호화된 실시간 P2P 메시징. 서버도 내용을 알 수 없습니다.

4

블록체인 기록

메시지 해시가 자동으로 opBNB에 벌크 기록되어 무결성을 보장합니다.

Roadmap

개발 로드맵
